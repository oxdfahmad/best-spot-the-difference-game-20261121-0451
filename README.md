Twin Lanterns is a spot-the-difference game with three original hand-drawn scenes: a lantern market at dusk, a moonlit koi pond, and a snowy lighthouse cove. Each scene hides seven differences between two near-identical pictures — find them all before the timer runs out.

## How to play

- **Find a difference:** click it on either picture — a gold ring marks it on both.
- **Wrong clicks** cost 3 seconds and break your combo; chained finds build the combo bonus.
- **Hints (H):** reveal one unfound difference for 50 points, 3 per round.
- **Timer:** 150 seconds per scene. Clearing a scene banks a time bonus and stars.
- **Keys:** H hint · P pause · M sound · R restart · Enter to start / continue.
- All art is drawn in code on canvas and all sounds are synthesized — no image or audio files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

The hand-in program writes the entry to the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
